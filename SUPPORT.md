# Support

ADDS-PIM is independently developed and currently provided as a nearly feature-complete beta.

## Bugs

For a reproducible software defect, open a **Bug report** using the GitHub issue template.

Please include a minimal reproduction, relevant environment details and correlation/request IDs where useful. Never post secrets or unnecessary information from a production environment.

## Questions and discussions

For installation, configuration, architecture, evaluation or general usage questions, please use **GitHub Discussions**.

Discussions are the preferred place for topics such as:

- installation and lab setup
- IIS and gMSA configuration
- Active Directory PAM and TTL memberships
- Kerberos and Windows authentication
- certificate and signing architecture
- MFA / FIDO2 / WebAuthn / TOTP
- least-privilege delegation
- architecture and design questions
- evaluation and proof-of-concept scenarios
- ideas that are not yet concrete feature requests

Use the **Q&A** category for questions where you are looking for a specific answer.

Use **Ideas** for broader proposals or design discussions that are not yet defined well enough to become a feature request.

## Feature requests

For a concrete, actionable feature proposal, use the **Feature request** issue form.

If the idea still needs discussion, trade-off analysis or architectural clarification, start a Discussion first.

## Documentation

For missing, unclear or incorrect documentation, use the **Documentation improvement** issue form.

## Security vulnerabilities

Do **not** open a public issue or discussion for security vulnerabilities.

Follow the private reporting instructions in [`SECURITY.md`](SECURITY.md).

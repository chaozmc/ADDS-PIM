# Support

ADDS-PIM is independently developed and currently provided as a feature-complete beta.

## Bugs

For a reproducible software defect, open a **Bug report** using the GitHub issue template.

## Installation and usage questions

Use the **Installation or usage question** issue form.

## Feature requests

Use the **Feature request** form and describe the operational or security problem the change would solve.

## Security vulnerabilities

Do **not** open a public issue. Follow [`SECURITY.md`](SECURITY.md).
